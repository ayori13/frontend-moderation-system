# Система модерации объявлений
 
Приложение представляет собой интерфейс модератора для проверки объявлений: список, детальная страница и статистика.

## Стек

- **React 18 + TypeScript**
- **Vite** — сборка и dev-сервер
- **React Router** — роутинг
- **React Query** — работа с запросами и кэширование
- **Axios** — HTTP-клиент
- **Express.js (готовый сервер из задания)**

Выбор сделан для удобства разработки: быстрый запуск, типизация и простая работа с API.

## Структура проекта

```
project/
  server/        ← готовый API-сервер из задания
  client/        ← интерфейс модератора (React)
  README.md
  .gitignore
```

## Запуск проекта

### 1. Установка зависимостей

#### Сервер
```
cd server
npm install
npm start
```

Сервер будет доступен по адресу:  
http://localhost:3001/api/v1

#### Клиент
В отдельном терминале:
```
cd client
npm install
npm run dev
```

Клиент будет доступен по адресу:  
http://localhost:5173/

## Основные страницы

### `/list`
- Список объявлений
- Фильтры (статус, категория, цена, поиск)
- Сортировка
- Пагинация
- Переход в карточку объявления

### `/item/:id`
- Полная информация об объявлении
- История модерации
- Действия: одобрить, отклонить, отправить на доработку

### `/stats`
- Общая статистика работы модератора
- Графики и показатели

## API

Описание API находится в файле `server/schema.yaml`  
Формат: OpenAPI 3.0.
